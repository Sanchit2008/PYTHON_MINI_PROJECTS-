This is my second python project. In this project i have created a referential, and dynamic linked list in python. 
Following are the functions i have added to make this linked list dynamic and powerful :

1. len() This function returns the no. of nodes in our ll
2. indexing,negative indexing to access nodes through index no.
3. nsert_head() This function adds node from head position
4. append() This function adds node from last or tail position
5. insert_after() This function adds node after other specified node 
6. print() This function prints the linked list in proper manner
7. clear() This function deletes all the nodes and makes an empty ll
8. del_head() This function delete node at the head position
9. pop() This function delete node at the tail position 
10. remove() This function deletes node with specified data
11. search() This function returns the index no. of node containing specified data
12. del() This function removes the node at specified index no.
