This is my third python project. In this project i have created a stack data structure in python. 
Following are the functions i have added to make this stack :

1. len() This function returns no. of nodes in our stack
2. push() This function pushes a new element in our stack at top position
3. pop() This function deletes the top element in our stack and returns it (LIFO METHODOLOGY)
4. peek() This function is used to return the element at the top of stack
5. print() This dunder function is used to print the elements in stack in proper format in terminal
6. Is_Empty() This function is used to check whether our Stack is empty or not
