This is my first python project.
In this project i have created a referential, and dynamic array same as modern list in python using an array of C++.
I have imported the array from a module known as Ctypes.
Following are functions i have added to the array to make it more like modern list:
1. len() this function returns the no. of elements in our array
2. append() this function adds given element at the last in our array
3. print() this function prints our array like list in python
4. getitem() this function is used to access our array with the help of indexing, negative indexing and slicing
5. pop() this function is used to remove the last element of our array 
6. clear() this function is used to delete all the items in our array
7. find() this function is used to find the index no. of any value passed in te function in our array
8. insert() this function is used to add any element at whatever index no. specified by user
9. remove() this function is used to remove an element from our array by value
10. delete() this function is used to remove an element from our array by index no.
11. min() this function is used to find the minimum value in your array
12. max() this function is used to find the maximum value in your array
13. sum() this function is used to return sum of all the elements in our array
14. extend() this function is used to extend our array by adding another list,tuple,dict with it
15. merge() this function is used to merge our array by with another list,tuple,dict with it
16. sort() this function is used to sort our array in ascending order
